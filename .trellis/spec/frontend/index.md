# Frontend Development Guidelines

> Best practices for frontend development in this project.

---

## Overview

**This project does not have a frontend.**

`aesyiu` is a pure Node.js library designed to be consumed by backend applications or CLI tools. There are no UI components, React/Vue/Svelte code, DOM manipulations, or CSS.

All development guidelines for this project are in the [Backend Development Guidelines](../backend/index.md).
